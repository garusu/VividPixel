<h1 align="center">Vivid Pixel</h1>

Vivid Pixel is a minimalistic, lightweight, fast, and intuitive tool for creating pixel art right in your browser, powered by Vue.

## Demo

Live Demo: https://garusu.github.io/VividPixel/

<p align="center">
  <img src="./docs/screenshot.png" alt="Screenshot" width="90%">
</p>

## Features

* Convenient drawing tools
* Layer management
* Instant import and export
* Hotkeys support

## Build

1. Сlone the repository
```bash
git clone https://github.com/garusu/VividPixel.git
```

2. Install dependencies
```bash
npm i
```

3. Build
```bash
npm run build
```
